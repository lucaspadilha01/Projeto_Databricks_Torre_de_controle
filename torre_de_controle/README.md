# torre_de_controle

Bundle do **Projeto Farol**. A documentação completa (problema, arquitetura, decisões, resultados, capturas de tela e como rodar) está no [README da raiz do repositório](../README.md).

Atalhos: `databricks.yml` (bundle), `resources/` (job, pipeline, dashboard, Genie), `src/` (SQL e notebooks), `scripts/` (geradores de dashboard e Genie) e `minha-torre/` (Databricks App, bundle próprio).
